# Synapse

An on-premise-first AI knowledge assistant: a document knowledge base with grounded, cited chat over an organization's own documents. It runs on modest hardware (CPU only, 16 GB RAM) with an optional GPU tier, and is built for Turkish and English.

Status: foundation. The architecture is decided; the application is being built.
